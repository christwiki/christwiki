# Languages

Christwiki is written in English and built to be read in any language. How that works, how a language is added and how entries are translated is described in the theme's guide:

**[chronowiki: Languages](https://github.com/christwiki/chronowiki/blob/main/docs/languages.md)**

This page holds what is Christwiki's own.

## Where things are

| | |
|---|---|
| `wiki.config.ts` | the languages, and the names of the map regions in each |
| `src/messages/<code>.ts` | Christwiki's own wording in each language, laid over the theme's: the tagline, the opening lines, the examples for the date labels |
| `src/content/i18n/<code>/` | translations of entries |
| `src/content/pages/` | pages of running text, such as the method page, translated like entries |

```bash
npm run i18n -- status de --missing              # what is done, what is out of date, what is left
npm run i18n -- new de events/council-of-nicaea  # start a translation
npm run i18n -- stamp de                         # after revising out-of-date translations
```

## Rules for the translator

The standard in [authoring-guide.md](authoring-guide.md) holds in every language, together with the rules in the theme's guide. Two things are specific to Christwiki:

- **Quote Scripture only from the public-domain version named for your language** in the theme's language definition (for German, the Lutherbibel of 1912). Quote other sources only from a public-domain translation in your language, named in the source's overlay. Otherwise paraphrase: your own translation of a passage does not go inside quotation marks, beyond a phrase of two or three words.
- **A translation is checked like an entry**: by someone who did not write it, against the English entry and, for anything quoted, against the source. Record the day in `translated`.

## German

German (`de`) is a preview language: built by `npm run dev` and by `PREVIEW_LOCALES=true npm run build`, left out of a release until it is switched to live in `wiki.config.ts`. Its interface is complete, and so are the eras, the threads and the method page. One event with its person, place and source is translated as a worked example (`first-deportation-to-babylon`). Everything else falls back to English.
